# Журнал: кодинговий агент проєкту

- **Дата запису:** 2026-09-08
- **Інструмент:** Claude Code (CLI)
- **Клас інструменту:** автономний кодинговий агент із доступом до файлової
  системи робочої копії та можливістю виконувати команди оболонки
  (на відміну від чат-асистента без доступу до репозиторію та від
  автодоповнювача коду в IDE).

## Спосіб доступу до репозиторію
Агент запускається з кореня робочої копії `rental-is/` і працює з локальними
файлами. Доступу до облікового запису віддаленого сховища не має:
`git push` виконує виключно студент.

## Дозволені операції
- читання будь-яких файлів репозиторію, аналіз структури проєкту;
- створення та редагування файлів у `src/`, `tests/`, `docs/`;
- пропозиція правок до `spec/` — лише з подальшим переглядом людиною.

## Заборонені операції
- `git push`, `git reset --hard`, `git rebase`, будь-яка зміна історії;
- зміна `.gitignore` та конфігурації Git;
- автоматичне прийняття правок у `spec/` без перегляду через `git diff`.

## Порядок фіксації змін агента
Кожен коміт, вміст якого згенеровано агентом, містить трейлер
`Change-Origin: agent`. Ручні зміни — `Change-Origin: human`.
Гілки з правками агента мають префікс `agent/`, ручні — `human/`.
