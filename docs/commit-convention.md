# Конвенція повідомлень комітів

Формат: `<префікс>: <що зроблено, наказовий спосіб, українською, до 72 символів>`

| Префікс  | Тип артефакту / дії SDD |
|----------|--------------------------|
| `spec:`  | зміни у специфікації, описі задуму, вимогах |
| `test:`  | створення або зміна тестів |
| `feat:`  | реалізація функціональності в `src/` |
| `docs:`  | документація, діаграми, конвенції, журнали |
| `gate:`  | рішення контрольної точки (gate) SDD-циклу |
| `fix:`   | виправлення дефекту без зміни вимоги |
| `chore:` | службові зміни: структура, конфігурація, залежності |

## Трейлери
- `Change-Origin: human` — зміну підготувала людина;
- `Change-Origin: agent` — зміст згенеровано кодинговим агентом і перевірено людиною;
- `Refs: OQ-xx` — коміт пов'язаний із відкритим питанням.
