# rental-is — Інформаційна система сервісу подобової оренди житла

Навчальний проєкт з дисципліни «Проєктування інформаційних систем» (НТУУ «КПІ ім. Ігоря Сікорського»).
Репозиторій організовано як єдине сховище артефактів SDD-циклу.

## Структура
- `spec/`  — специфікації та опис задуму (джерело істини для рішень)
- `src/`   — програмний код
- `tests/` — модульні та інтеграційні тести
- `docs/`  — документація, діаграми, конвенції
- `logs/`  — журнали взаємодії з кодинговим агентом, записи рішень і контрольних точок
